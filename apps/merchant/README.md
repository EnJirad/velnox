# VelMerchant

Merchant management portal (Next.js App Router).

## Foundation includes
- Dashboard layout with sidebar navigation
- Auth provider scaffold + API client wired to backend `/api`
- Route placeholders: `/dashboard`, `/dashboard/{shop,products,inventory,orders,analytics}`
- Feature-based folders under `features/`

## Development
\`\`\`bash
pnpm --filter merchant dev
